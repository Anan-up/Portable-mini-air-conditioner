## 項目誌：朋友圈便攜小空調

此為**純前端、單檔之趣味網頁**——於瀏覽器中模擬空調一台，可「開關、製冷製熱、調溫」，並配以按鍵之音、風聲之響，乃昔日微信朋友圈盛行之整蠱玩梗小物（傳鏈於人曰：「天熱矣，贈君空調一台」）。凡諸資源皆內嵌其中，不假外求，雙擊檔案即可把玩。

### 技術構成

| 部類 | 實現之法 |
|---|---|
| 體積 | 約七百六十千字節，單一 HTML，**無一外部請求**（吾遍覽全文，確無外鏈） |
| 界面 | 純以 CSS 繪空調機身，及「冷氣」吹拂之動畫三條；按鈕圖標為內聯 SVG（雪花／電源／太陽／升降溫） |
| 數字字體 | 內嵌 base64 之 TTF 字體，使溫度之顯現有數碼管之觀感 |
| 音效 | MP3 三段（按鍵「嗶」聲、約九秒之開機音、循環之風聲），皆以 base64 data URI 內嵌 |
| 狀態存儲 | 以 localStorage 記模式與溫度，**三十日有效**；若隱私模式等禁用 localStorage，則自動降為記憶體存儲，以防腳本崩壞 |

### 交互之要

- **按鈕凡五**：開關（電源鍵）、製冷 ❄、製熱 ☀、升溫、降溫
- **溫度之域**：攝氏十六至三十一度；未開機時，調溫切模式皆不效（以模擬真實空調也）
- **應季之默認**：十一月至次年二月，默認製熱二十八度；餘月默認製冷二十二度——過期重開，則依季節自復其初
- 開關機之際，面板、指示燈、吹風動畫皆同時隱現

### 最見匠心者：風聲之引擎

JS 注釋明言「復刻原版時序」，其制也甚用心：

- 以 **WebAudio API** 播之：開機音播至七秒半，循環風聲自始接入；二者尾首相銜皆風聲雜訊，**重疊約一秒七**，故聽之渾然無縫
- 風聲於**半秒至五十九秒**之間循環，略去開頭起音
- 關機之時不驟然截斷，而**以〇·六秒漸隱**，末後補短「嗶」一聲
- 若 `fetch`／`decodeAudioData` 不可用，則自動降為尋常 `<audio>` 加定時器之策，且先播後停以預載，使接入之際無隙
- 頁面既載即預解音頻，以保按鍵零延遲
