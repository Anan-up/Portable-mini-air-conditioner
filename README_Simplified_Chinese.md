## 项目介绍：朋友圈便携小空调

这是一个**纯前端、单文件的趣味网页**——在浏览器里模拟一台可以「开关、制冷制热、调温度」的空调，配按键音和风声，属于当年在微信朋友圈流行的整蛊/玩梗类小应用（给别人发链接说「天热了，给你台空调」）。所有资源全部内嵌，不依赖任何外部服务器，双击文件就能玩。

### 技术构成

| 部分 | 实现方式 |
|---|---|
| 体积 | 约 760KB，单 HTML，**零外部请求**（我扫描全文确认没有任何外链） |
| 界面 | 纯 CSS 画的空调机身 + 3 条吹风的"冷气"动画，按钮图标为内联 SVG（雪花/电源/太阳/升降温） |
| 数字字体 | 内嵌 base64 的 TTF 字体，让温度显示有数码管效果 |
| 音效 | 3 段 MP3（按键"哔"声、约 9 秒开机音、循环风声）以 base64 data URI 内嵌 |
| 状态存储 | localStorage 记录模式和温度，**30 天有效**；隐私模式等禁用 localStorage 时自动降级为内存存储，防止脚本崩溃 |

### 核心交互逻辑

- **五个按钮**：开关（电源键）、制冷 ❄、制热 ☀、升温、降温
- **温度范围**：16–31°C，未开机时调温/切模式无效（模拟真实空调）
- **季节默认值**：11 月~次年 2 月默认制热 28°C，其余月份默认制冷 22°C——过期后重开会自动按季节重置
- 开关机时面板、指示灯、吹风动画同步显隐

### 最有讲究的部分：风声引擎

JS 注释里明确写了「复刻原版时序」，实现得比较用心：

- 用 **WebAudio API** 播放：开机音播放 7.5 秒后，循环风声从头接入，两者尾部/头部都是风声噪声，**重叠约 1.7 秒**做到听感无缝
- 风声在 **0.5s ~ 59s** 区间内循环，跳过开头的起音
- 关机时不硬掐断，而是 **0.6 秒淡出**，最后补一声短"哔"
- 若 `fetch`/`decodeAudioData` 不可用，自动降级为普通 `<audio>` + 定时器方案，并先播再暂停来预加载，消除接入空隙
- 页面加载即预解码音频，保证按键零延迟
